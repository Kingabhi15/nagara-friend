### 🚀 Features

- 📍 **Auto GPS Lock** - Gets exact location (12.8760, 77.5961) with Bannerghatta maps
- 🧠 **Gemini 3.6 Flash AI** - Analyzes civic photos (garbage, potholes, drainage)
- 🇮🇳 **Kannada + English** - Full bilingual support (ಕನ್ನಡ / EN toggle)
- 🎯 **Severity Scoring** - 0-100 priority with HIGH/MEDIUM/LOW badges
- 🏢 **Dept Auto-Assign** - BBMP, BWSSB auto detection
- 🔮 **What-IF Prediction** - 72h risk + 7 days impact
- 📄 **PDF Report** - One-click download with GPS & Map link
- 📱 **Mobile First** - Works on any phone, no install needed
- 🧪 **Demo Mode 92/100** - Works without API key for judges

### 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JS (No framework - Fast load)
- **AI:** Google Gemini 3.6 Flash via Generative Language API
- **Maps:** Google Maps Embed API
- **PDF:** jsPDF + html2canvas
- **Hosting:** GitHub Pages
